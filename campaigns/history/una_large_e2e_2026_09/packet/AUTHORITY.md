# Frozen campaign authority

## Objective
Improve end-to-end CPU service and sustained successful-job throughput on large observed street-network workloads relative to current CSR-optimized main, without changing required API, floating-point execution, science, state, artifacts or ordinary installation. There is no supplied production SLA. The default screening/qualification thresholds in DECISION.md are policy constants for proxy improvement, not a claim about the user's target.

## Authorized portfolio

A1: preserve per-pop neighbor snapshot while reusing private scratch.
A2: enumerate potentially reachable destinations locally, preserve original filtered destination sequence.
A3: reduce/init private scope state only after large-scale measured materiality and projection proof.
F1: release GIL in flow loaders only after ownership audit, keeping logical stripe partition and sum order.

These are hypotheses, not accepted transformations. Do not implement all by default. At most six optional prototypes. No unrelated flow optimization or new sparse Dijkstra backend.

## Protected behavior and non-goals
Ordered CSR stays. No graph reordering, contraction, edge deduplication, approximate nearest neighbor, changed sort/tie policy, changed route model, altered metric formula, precision, fastmath, FMA policy, cutoff or reduction tree. No GPU/native backend, broad cross-run cache, new runtime framework or public backend option. No repair of inherited numerical bugs inside a performance claim. A separately recorded packaging prerequisite may be proposed if the baseline cannot install, but must be applied equally for the comparison and cannot silently become a runtime patch.

## Delegated authority
Workers choose private names, test utilities and ordinary implementation details inside dossiers. They may not invent missing input fields, fixture licenses, target hardware, performance results, independent reviews, or numerical equivalence. Resource/workload preregistration is local engineering work, not a request to the user after each task.

Publication authorization is one-time for delivering this packet to main. The campaign creates local reviewed commits; subsequent pushes, main merges and releases require a new explicit instruction. Never force-update branches or overwrite user work.
