# CPU throughput campaign

1. Inventory current fork and machine. Freeze source, workload proxy, resource budget, and benchmark boundaries.
2. Verify the historical extracted oracle against the complete pinned baseline source. If mismatched, rebuild the oracle from immutable baseline and invalidate dependent old evidence.
3. Reproduce baseline public API on a tiny genuine GIS fixture and capture arrays, state/chronology-sensitive outputs, warnings/errors, and artifacts.
4. Integrate the ordered-CSR candidate in an isolated worktree with exact unsupported-domain fallback.
5. Run L0/L1 adversarial exactness tests, including duplicates, self-loops, signed zero, nonfinites, ownership/layout, and baseline-versus-candidate search state.
6. Run genuine L2 public API, flow-gravity-cap dependency, and CSV/GeoJSON/Feather comparisons.
7. Build/install wheels for baseline and candidate in separate clean environments. Verify imports resolve to installed wheel paths and candidate path actually executes.
8. Profile complete candidate. If CSR no longer has material service coverage, stop CSR micro-optimization.
9. Jointly tune workers, Numba threads, queue depth, and writer concurrency under equal CPU/RAM limits. Benchmark owner has exclusive machine execution.
10. Admit at most one optional scratch/state experiment only if its dossier proof and Amdahl/ROI gates are satisfied.
11. Freeze final candidate, run alternating-order confirmation, cold-start diagnostics, memory process-tree sampling, and actual target if supplied.
12. Independent review source/proof/evidence. Rehearse proposed merge in a disposable worktree.
13. Produce decision.json, RESULTS.md, evidence ledger, candidate/rejected registers, and merge_manifest.json. Stop.
