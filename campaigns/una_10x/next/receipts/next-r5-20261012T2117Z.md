## Incident found and fixed during self-review (before the external review)

The first `_NETWORK_RESIDENT_KEYS` tuple omitted `"z"` — an elevation payload
would have silently bound `net.z = None` on every lease row (parity break the
smoke-grid battery could NOT catch: its network has no z). Additionally, the
payload carries `"z": None` (key present, value None) when there is no
elevation, so the bind's guard must test the VALUE (`r.get("z") is not None`),
not key presence — the first fix attempt crashed 8 tests and was corrected.
Both covered by `test_r5_optional_fields_survive_residency` (binds a z-carrying
resident and asserts `net.z` equals the payload on a fresh copy).
