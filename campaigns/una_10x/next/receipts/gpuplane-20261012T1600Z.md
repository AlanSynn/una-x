## Operational lessons (salloc on this cluster)

1. `salloc <cmd>` runs `<cmd>` on the LOCAL login node — node execution requires `srun`
   inside the allocation. First attempt ran locally and honestly returned
   `device_unavailable` (typed blocker worked as designed).
2. Bare `srun --gres=gpu:1 …` failed step creation ("Invalid generic resource (gres)
   specification"); the salloc→srun-inside pattern works.
3. `/tmp` is node-local — scripts must live on shared `/storage` (exit 127 first try).
4. gpu-v100 queue fluctuates: one PD window, then immediate allocation ~4 min later.
