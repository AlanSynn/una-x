## Implementation (bridge module only; `src/urban_network_analysis/Engines/_gpu_fold.py`)

- `_phase_b_fast`: verbatim transplant of the `_phase_b` loop under
  `@_njit(cache=False, nogil=True, parallel=False)` (sequential order keeps the precedence
  law trivially; no prange — the order law leaves no justification to try one). Fallback
  `_phase_b_fast = _phase_b` when numba's njit import fails (same availability class as
  the cuda import). Early exit is intentionally NOT preserved — the contract is the
  returned code only.
- Precedence law verified from source and pinned by the battery: per origin ascending,
  (a) hi<lo or lo<0 -> 1; (b) hi>nnz -> 1 (before any element access — memory safety);
  then per j ascending in [lo,hi): (c) `ids_all[j] <= ids_all[j-1]` -> 2, (d) out of
  [0, node_count) -> 1. **(c) is checked BEFORE (d) at the same j, so at one j code 2
  wins; across j the earlier j's class wins; origin order precedes both.**
- Callsite (`gpu_replay_fold`) now calls `_phase_b_fast`; the refusal chronology is
  unchanged (Phase-B refusal still precedes `require_device()` and all device work). The
  kernel and device path are byte-identical — outputs are a function of (kernel, inputs),
  both untouched.
