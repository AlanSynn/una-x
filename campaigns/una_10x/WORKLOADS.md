# Workload freeze, not benchmark hunting

User production dataset and job mix are currently unavailable. Use observed proxies without
calling them production. No radius/metric/job-count change after viewing candidate ratios.
W00 must freeze actual counts, hashes, full Settings/Execution options, original order, output
formats, profile and sampling before medium candidate timing. Observed morphology is a property
of the source data; generated grids written as GeoJSON are still synthetic.

## Required cells
SYN_TINY and SYN_DENSE: preserve the prior tiny/search-dominated losses as regression controls.
SYN_LOCAL: reproduce selected prior local-domain fixtures, initially smaller, then final pinned
case once a direct-checkout bit bridge passes. These explain work scaling, not the primary claim.
OBS_SINGLE: one full observed network with actual point layers; one prespecified analysis radius,
all four accessibility fields, CSV/GeoJSON/Feather when currently requested/supported, complete
public RunAccessibility. No preparatory private calls outside its declared end-to-end boundary.
OBS_COHORT (default primary): public RunBatch over the same full observed input, 32 distinct
exponential-gravity beta rows, fixed logistic KNN and all original output flags. Publish every row,
its independent mutable results, final public state and composite outputs if requested. Exact
beta vector is frozen before candidate timing. Starting policy for meter-based proxy costs:
32 binary64 linspace values .001 to .004, all recorded as uint64 bit patterns. This is an
experimental policy, not a sourced travel-behavior claim. Respect upstream tutorial settings
instead when their recorded workflow supplies the actual target. Never invent local units.
OBS_MIXED: independently meaningful rows with changed radius/destination weights/obstacles or
cost/profile; include at least one graph-changing row that MUST split the routing cohort.
REPEAT_IDENTICAL: current final-result cache ENABLED in the baseline; a negative control against
calling cached answers a new structural 10x achievement.
COLD/SMALL: fresh process + cold JIT/cache diagnostic; tiny GIS and dense neighborhood controls.
OBS_FLOW: real aggregate-flow configuration through RunFlow/RunBatch with fixed logical stripe
partition, not replaced by a different route model. No 10x claim unless independently frozen.
HOLDOUT: second observed morphology/provider or city when available, not another crop/radius on
the same graph. Same-network holdout is useful but labeled as such. Missing data is explicit.
ACTUAL: user-supplied unreduced production workflow, when available; only this can establish L4.

## Pinned observed starting catalog
Prefer the repository's already validated observed workload manifests and retained input bytes.
Do not refetch mutable main URLs. A fallback observed dataset catalog is in inputs_catalog.json,
using the earlier audited upstream commit and Git blob hashes. Fetch in a separate acquisition
phase, verify Git blob size+SHA AND SHA-256, inspect CRS/geometry/columns and keep provenance.
Known files: Boston InnerCore network (2D/3D), Cambridge building centroids with population/jobs,
Cambridge transit points. File byte sizes/hashes are source metadata, not graph counts. Confirm
actual counts from the parsed data and record no silent filtering or dropping of invalid rows.
Sources may require independent license/provenance review; repository license alone is not an
assertion about all third-party dataset rights. No private data upload or paid data acquisition.

Use a full network for principal observed cases. For L2, a small exact fixture is separately
named and frozen; it never substitutes for the large cell. Any deterministic sampling for L2
is a NEW declared fixture with retained selected IDs. No execution tiling changes physical
boundaries or neighborhood access. Destination weighting affects the model; use the original
column or Count explicitly. Record elevation, obstacle and snap settings even when disabled.

## Deliberate scale experiments (secondary, bounded)
V/E extent at fixed local cutoff; D density on fixed graph; O/job volume; radius; and analysis
family are distinct axes. Choose at most two levels per axis in screening based on source-work
coverage. Do not execute a combinatorial grid. Candidate dispatch must generalize beyond a
single favorable fixture. Use held-out descriptors to audit thresholds, not to tune them.

## Refuse invalid comparisons
A different number of origins/destinations, a silently changed path model, different output
format obligations, no obstacle layer, wrong analysis dispatch, warmed candidate trace vs cold
baseline, or newly sampled input is not the same workload. Record invalidated runs and fix the
harness before proceeding. Caches and trace reuse may reduce evaluations, never requested jobs.
