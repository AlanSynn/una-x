# Exactness gates and adversarial matrix

## Independent oracle
B0 is immutable source at 361928e4ba38f34622cafe065b0025244db61368 under the frozen laptop dependency profile. Build reference and candidate wheels separately. First run B0 twice for determinism. No golden output may be generated by candidate code or loaded by filename-only reuse. Cache key includes source closure, wheel, Python/Numba/LLVM/NumPy/SciPy/geospatial versions, ISA, numerical flags, stripe partition, workload, harness and test hashes. Clear or isolate Numba cache after helper changes, because imported helper changes may not invalidate callers' caches automatically.

Existing CSR tests remain valuable but not sufficient for search/flow transformations. Run them with B0/candidate source paths explicitly set, L1_REUSE_DIR unset, unique caches and neutral cwd. Keep upstream/pre-CSR tests separately labelled. Installed comparison cannot import reference implementation into candidate package runtime.

## L0: algebra and state
Enumerate tiny graphs with 0..4 network nodes where the baseline accepts them, including empty edges, duplicate directed incidences, unequal parallel weights in both orders, self-loops, degree-one terminals, disconnected components, isolated origins/destinations, same start/end terminal with unequal costs, and overlapping origin/destination host edges. Invalid shapes/indices/dtypes use baseline error/fallback tests, not unsafe JIT indexing.

Float fixtures: +0/-0, smallest/largest subnormals, ordinary finite values, values adjacent by nextafter to cutoff, sentinel R+1==R and overflow boundaries, finite weights near addition overflow, equal/near-equal shortest labels, tied destination distances with unequal destination weights, nonpositive/custom weights and NaN/Inf refusal domains. Numerical hazard probes are bounded child processes. No large nonfinite random graphs.

A1 trace compares labels, eligible offsets/weights and heap content after EVERY pop and update. A2 compares candidate destination IDs, adjusted distances and the final retained distance/weight sequence before unchanged metric calls. A3 validates projection and scratch state before/after EACH origin, including epoch rollover simulation. F1 compares fixed-stripe partial AB/BA/node arrays before final reduction. F2 compares overlap IDs, both sort orders, contamination, q_sum, scale, seeded shares, tree-propagation arrays, delivered volume and global outputs after EACH OD. F3 compares distance AND predecessor arrays across chunk boundaries and all sparse output arrays.

Use a Python trace only as an explanatory oracle. Also run actual baseline and candidate compiled functions on every relevant small adversarial case. Code-generation changes can invalidate a mathematical proof. Exact equality is dtype+shape+bytes for deterministic arrays; diagnose first differing step/key/index. Never switch to approximate comparisons after mismatch.

## L1: compiled real-input kernel boundaries
Capture actual typed arrays from observed B0 topology, including int32 endpoint inputs. Compare original and candidate with same graph/order/weights. Check input immutability, output ownership/aliasing, arrays after multiple sequential calls, multiple independent workers, and unsupported-domain fallback engagement. Validate all kernel specializations used by final workloads, not just the first cached signature.

A no-race claim requires per-worker scratch and repeated concurrent runs with fixed logical partition. Thread sanitizer is optional if unavailable; do not claim it ran. For F1 inspect targetoptions/LLVM/native compilation and sample concurrent execution. For A1/A3 inspect compiler allocation/vector behavior; do not assume array syntax allocations survived or that scalar loops vectorized.

## L2: observed public chronology and protected paths
Run O2 observed accessibility and aggregate flow with auto gravity-cap. Capture Settings before/after each public call, readiness flags, resolved cap, topology arrays, metrics/edge/node/directional arrays, geometry/CRS/schema and all artifacts. Add sequential reuse on the SAME UNA object where public API supports it: accessibility then flow, changed settings between calls, obstacles enabled then absent, and repeated export/error paths. These tests can reveal inherited state bugs; do not fix them silently, compare B0 behavior and refuse the changed region if necessary.

Protected synthetic cells: turns off/on, elevation off/on and no-Z, obstacle/observer paths, node flow enabled/disabled, zero-weight and unreachable cases, K-alternative flow, dense/pairwise ODM including shape and row order, different output flags, malformed Settings and files, missing optional dependency behavior. Keep no-op/unsupported paths original. If a protected case is already nonterminating in B0, retain hazard evidence and scope the claim rather than dropping it from reports.

Artifact equality: byte hashes first. Time-directory names can be translated using the declared timestamp policy only. For nondeterministic writer metadata established by two B0 runs, compare exact field schema, data values/order/dtypes/CRS and preserve an allowlist naming just the variable fields. No broad 'ignore metadata' flag. Finite bits, nonfinite masks and signed zero comparisons remain separate from textual round-trip comparison.

## L3 and L4
L3 profiles and selects on observed frozen workloads, using installed-path screening for final promotion. Test interaction after combining candidates: individually exact does not imply identical scheduling/alias behavior when composed. Re-run affected kernel/public/installed descendants when shared code changes.

L4 is only a user-provided actual target and immutable final source. Missing U4 is unavailable. A large synthetic or observed proxy is not L4 by size alone. Required release/CI matrix is deferred to final integration; absent CI is not passed CI.

## Review records
Reviewer is independent of implementation. It names source/test/evidence hashes, verifies the proof against actual code, checks every refusal/early return and rejects unsupported claims. If independence is unavailable, mark review_pending. Reviewers may reuse verified unchanged evidence, but must rerun suspicious or missing central checks. Never claim 'all gates' based only on counts of test files.
