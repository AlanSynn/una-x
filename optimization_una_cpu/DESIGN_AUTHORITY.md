# Design authority

## Objective
Maximize real CPU throughput for the current UNA application without changing required semantics, numerical behavior, API, artifacts, errors, state transitions, operational guarantees, or ordinary install experience. The actual user production workload/throughput target is currently unavailable, so genuine tutorial data may qualify a proxy only.

## Mandatory change under evaluation
Replace repeated per-node edge rescans in the non-turn accessibility CSR builders with a stable incidence grouping that preserves each adjacency row's original incidence order. Unsupported inputs must use the original implementation.

## Frozen scope
- Public API/import/package/settings defaults and output schemas remain unchanged.
- Dijkstra/search semantics, reduction order, dtypes, cutoffs, snapping, turns/elevation/obstacle behavior remain unchanged.
- No cross-run cache or hidden workload reduction.
- Do not replace one flow engine with another.
- No GPU, CUDA, Metal, OpenCL/SYCL, new native extension, or backend registry in this campaign.
- One optional follow-up only: private scratch/state reduction if admitted by post-CSR profile and exact proof.
- External independent-job scheduling may be tuned. Existing public RunBatch semantics are not casually parallelized.

## Delegated decisions
Claude Code owns ordinary helper structure, fixture implementation, local worktree layout, portable process launching, profiler mechanics, packaging repairs, and bounded refactors inside these constraints.

## Completion
Promote only with exactness, genuine public-path and installed-wheel evidence, bounded memory, strongest equal-resource CPU comparison, and review. Missing actual workload prevents claiming the original production target is met.
